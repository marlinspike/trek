# config

Everything you set for the game lives in this folder. Only this README and the example files are in git; your own files stay on your machine.

You don't need a text editor for most of it: **Settings** on the game's main menu (or **S**) changes `settings.json` and your officers' names, ranks, traits and response style in `officers.toml`, saving each change at once. It writes only the line you change in `officers.toml`; everything else there stays as you wrote it.

| File | What it holds |
|---|---|
| `settings.json` | Window size, speed, sound (`volume` 0 to 1, `muted`, `sounds`: which version of the phaser and torpedo sounds, a to d, and `hum`: the ship's engine hum, 0 to 1, 0 for none), whether the map jolts when your ship takes a heavy blow (`jolt`), how the game is drawn (`renderer`: `auto`, `gpu` or `software`, and `bloom`: the *Light and glow* switch, both set on the main menu's Display page), officer chatter, Custom battle choices, the officers' language model, the Bridge setting (`bridge`: `hud bridge full|quiet|classic` and its parts), speaking orders (`voice`: engine, push-to-talk key, server address, model), the officers' spoken voices (`speech`: `enabled`, `speak` all|orders|urgent, `volume` 0 to 1, `rate`, `captains`, `engine` auto|system|piper|off, and `cast`: the voice you picked for an officer or race; set on the main menu's Officers' voices page or with `speak` in battle) and your career (`career`: each officer's trust and the ribbons you've earned). The game writes it; `begin --llm ...` edits the `llm` part, including `llm.character`, an optional second model for character voices (richer Klingon, Romulan and other alien speech for enemy captains and officers; set on the main menu's Character voices page, or see the in-game manual's language model page). Copy `settings.example.json` to start one by hand. |
| `officers.toml` | Your officers, shaped however you like: name and rank, traits, `response_style` (how they answer: length, tone, register), a whole new persona, or a background, interests and quirks added to the one they have, and their own lines for any moment (`idle` lines come in quiet moments). With a language model they shape how each officer talks; their lines work without one. Copy `officers.example.toml` to start. |
| `orders.toml` | Your named tactical orders: a name and a list of console lines, such as `beta-1`. In battle, `execute order beta-1` runs them. Copy `orders.example.toml` to start; until you do, the examples are loaded. Orders you `record` in battle are added here (starting from the examples, the first time). |
| `hails.toml` | Your own lines for enemy captains answering a hail, used when there is no language model. Same layout as `src/begin/content/data/hails.toml`: a `[klingon]`, `[romulan]`, `[orion]` or `[default]` table with any of its lines; yours replace the shipped ones line by line. |
| `wheel.toml` | Your own command wheel: copy `src/begin/content/data/wheel.toml` and change the slices. Each slice is a console line. |
| `alerts.toml` | Your own alert conditions (`alert red`, `yellow`, `green`): copy `src/begin/content/data/alerts.toml`. |
| `phrasebook.json` | Plain words the language model worked out once, kept so the same words work at once next time. Delete a line to forget it. |
| `voice/` | For speaking orders: Whisper models you download from the voice page (`voice/models/`) and the Mac speech helper the game builds the first time. Safe to delete; they come back when needed. |
| `speech/piper/` | Optional: the Piper program and Piper voices (an `.onnx` file with its `.onnx.json` each) for the officers' spoken voices. See the manual's Officers' voices page. |
| `orders.cache.json` | The game's own note of how the language model put your plain-English order steps into console commands, so it doesn't ask again. Safe to delete. |
| `sounds/` | Your own sound effects, as WAV files named for the sound they replace: `phaser.wav`, `torpedo.wav`, and the others listed in `help sound`. Each one replaces the game's own. |
| `begin2.key` | Begin 2.0 key macros, one per line, such as `F2 fire all torpedoes`. |
| `tours/` | Tours of duty. The game keeps each tour in progress here (`<tour>.json`) and its captain's log (`<tour>-log.md`: edit your entries between the `captain` markers and the game reads them back). Tours of your own go here too, as `.toml` files in the format of `src/begin/content/data/tours.toml`. |
| `help/` | Manual pages of your own. A `.md` file here replaces the bundled page with the same name; new files become new pages. |
| `logs/` | The language model's debug logs, written only when you turn them on (`begin --llm log_prompts=on log_tokens=on`, or `"log_prompts": true` / `"log_tokens": true` under `llm` in `settings.json`). `llm-prompts.log` holds every prompt and reply in full with its tokens in and out, who asked and how long it took. `llm-tokens.json` keeps all-time totals and each game's calls and tokens, broken down by who asked; `begin --llm-usage` prints them. Safe to delete. |

API keys never go in here: they come only from environment variables (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `OPENROUTER_API_KEY`).

Set `BEGIN_HOME` to use a different folder. Older versions kept these files in `~/.begin-remake`. The first run brings them here, once: anything already in this folder wins, and settings missing from your `settings.json` (such as officer rapport) are filled in from the old one. The old folder is left alone, so you can delete it once you're happy.

Every officer is yours to configure in `officers.toml`: `name`, `rank`, `aliases`, `traits`, `response_style`, `persona`, `background`, `interests`, `quirks`, their `lines` for any event, and optionally a `rapport_floor` (-1 to 1), the lowest their regard for you can fall however you treat them. `officers.example.toml` lists them all, with a Worf who cooks as an example. Under `hidden` in `settings.json` the game keeps its record of officer rapport; anything else there from older versions is dropped the next time it runs.
