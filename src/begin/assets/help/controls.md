## Time

| Key | Action |
|---|---|
| **Space** | Pause or resume. Orders still work while paused. |
| **[** and **]** | Slower or faster: 0.25×, 0.5×, 1×, 2×, 4×. One cycle is one second at 1×. |

## Helm

| Key or mouse | Action |
|---|---|
| **W** / **S** | Warp up or down by one |
| **A** / **D** | Turn 15° to port or starboard (hold **Shift** for 5°) |
| Right-click the map | Steer toward that point |
| **Shift** + right-click a ship | Pursue it |

## Weapons and targeting

| Key or mouse | Action |
|---|---|
| Left-click a ship, or **Tab** | Select a target (**Shift+Tab** goes backwards) |
| **R** | Aim at a subsystem: propulsion, weapons, shields, power, sensors |
| **F** | Fire phasers |
| **T** | Fire torpedoes |
| **P** | Launch a probe at the target |
| **X** | Scan the target |
| **V** | Cycle the point-defense doctrine |
| **G** | Raise or lower all shields |

## Bridge

| Key or mouse | Action |
|---|---|
| Right-click a ship, or **E** for your target | Open the command wheel. See [[bridge]]. |
| **1**–**8** with the wheel open | Pick a slice |
| **Y** / **N** | Make an officer's proposal so, or belay it |
| **Ctrl+Y** while typing | Accept the urgent proposal shown above the console |
| **O** | Open or close the counsel: each officer's plan from here. See [[counsel]]. |
| **1**–**4** with the counsel open | Go all in on that officer's plan |
| **Tab** while typing | Finish a command, ship, officer or order name |
| Hold **Right Alt** (Option on a Mac) | Speak an order; let go to send it. See [[voice-orders]]. |

## View

| Key or mouse | Action |
|---|---|
| Mouse wheel, **+** / **−** | Zoom (or type `range 8000`) |
| Drag, arrow keys | Pan the map |
| **C** | Centre on your ship and follow it |
| **Q** | Show phaser arcs |
| **I** | Damage view |
| **M** | Sound on or off. See [[sound]]. |
| Mouse wheel over the log | Scroll the console log |

## Console and help

| Key | Action |
|---|---|
| **Enter** or **/** | Open the command console. See [[console]]. |
| **↑** / **↓** in the console | Previous and next commands |
| **H** | Open this manual |
| **F1** | Open this page |
| **F2–F8, F10–F12**, **Ctrl+letter** | Run a key macro. See [[keys]]. |
| **Esc** | Close the counsel, the open window or text display, or open the battle menu |

## How much the panels show

The panels show what matters at a glance: warp, course, crew, hull, morale, and shield arcs coloured by strength. The Own ship panel's **Torpedoes** line says how many tubes are loaded and with what ("6/8 loaded · MK7 · 34 left") on every window size, and its **PD** button sets point defense. In the Weapons panel each tube names the torpedo it holds, green and with a full bar when loaded, amber and filling while it arms, "—" when empty and DMG when damaged; the count under **Tubes** is how many are loaded. On a short window the Target panel, and then the Weapons panel, become tabs at the bottom of the column, so nothing runs off the screen. Hover over the Own ship panel and it shows every number: shield strengths, maximum warp, power in and out, the magazine. Numbers ease to their new value instead of jumping, and flash briefly when they change: brighter for a rise, warmer for a fall.

| Command | What it does |
|---|---|
| `hud detail` | always show every number |
| `hud simple` | back to the essentials (hover a panel for the rest) |
| `hud` | say which it is |


## The main menu

| Key | Action |
|---|---|
| **Enter** | Quick battle |
| **P** | Patrol |
| **T** | Tour of duty |
| **C** | Coach & training |
| **H** | The manual |
| **F1** | This page |
| **S** | Settings (**D** opens Display, **V** Character voices) |
| **K** | The Enterprise's next pass meets a Klingon battle cruiser, which decloaks and fights her |
| **B** | Her next pass meets a Borg cube, which comes out of a transwarp conduit, trades a few salvos with her, adapts to her phasers and is destroyed |
| **Esc** | Quit: press it twice, so one Esc too many never ends the game (the **Quit** button needs only one click) |

Each button shows its key at its right end.

Left alone, the menu shows a pass that meets an enemy every few passes: the Borg cube first, a few seconds after the menu opens, then the Klingon and the Borg taking turns.
